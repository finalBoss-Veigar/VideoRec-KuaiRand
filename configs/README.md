# 配置怎么选

- `demo_suite.yaml`：人工合成数据，2个种子，5组设置，检查流程。
- `verification_real.yaml`：第二版交付验证使用的真实数据小实验，2个种子，9组设置，每组最多6轮。
- `real_suite.yaml`：供你亲手开展权重、特征消融和多任务对照，3个种子，11组设置，每组最多12轮。建议先复制文件并减少实验数，再逐步扩展。

配置中的`data`和`output`相对项目根目录解释；也可以通过suite的`--data`和`--out`覆盖。每组name只能包含英文、数字、下划线和短横线。

每个实验都会保存实际配置、数据身份、代码文件哈希、依赖版本、训练曲线、模型和验证指标。相同请求的已完成实验可跳过；中断实验不会自动接着训练，需要保留现场并使用新的输出目录。修改代码后再次执行同一个suite输出路径会被拒绝，请使用新版本目录。

参数`variant`表示特征组合，取all、no_user、no_video、context；命令行对应`--features`。配置里的学习率键名为`lr`。未知参数会报错，不会被忽略。

suite只运行训练与验证，不自动挑模型、不评价最终测试集。
